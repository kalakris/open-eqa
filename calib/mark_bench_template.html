How to mark

Each item is one model's answer to an OpenEQA question about a home. You see the human reference answer, plus any extra answers also accepted. Mark how well the response matches them, using the same 1–5 scale the LLM-Match judges use. Judge correctness against the references, not writing style or length.

  • 5: matches the answer, or any accepted answer.
  • 4: correct, with a small extra detail that is off or unverifiable.
  • 3: partly right, e.g. the right object in the wrong place, or the right place with a wrong detail.
  • 2: mostly wrong, with a small overlap.
  • 1: completely different from every reference.

Model names and judge marks are hidden. Use Unsure when the references leave it genuinely ambiguous. Everything saves as you go.
